# SQL Agent 智能搜索功能使用说明

## 📝 功能概述

SQL Agent 是一个智能搜索功能，可以将用户的自然语言问题转换为 SQL 查询语句，并返回查询结果。

**核心流程：**
```
用户输入自然语言问题 → 生成SQL语句 → 执行SQL查询 → 返回结果
```

---

## 🚀 快速开始

### 1. API 端点

**基础路径：** `/sql-agent`

提供三个接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/sql-agent/ask` | POST | 智能搜索（主接口） |
| `/sql-agent/examples` | GET | 获取示例问题列表 |
| `/sql-agent/schema` | GET | 获取数据库结构信息 |

---

### 2. 使用示例

#### 示例 1：查询评分最高的电影

**请求：**
```bash
curl -X POST "http://localhost:8000/sql-agent/ask" \
  -H "Content-Type: application/json" \
  -d '{"question": "查询评分最高的5部电影"}'
```

**响应：**
```json
{
  "success": true,
  "sql": "SELECT vod_id, vod_name, vod_score, vod_year, vod_area, vod_actor, vod_director\nFROM sakura_movdetail\nWHERE vod_score IS NOT NULL AND vod_score != ''\nORDER BY CAST(vod_score AS DECIMAL(3,1)) DESC\nLIMIT 5",
  "result": [
    {
      "vod_id": 12345,
      "vod_name": "电影名称",
      "vod_score": "9.5",
      "vod_year": "2023",
      "vod_area": "日本",
      "vod_actor": "演员名",
      "vod_director": "导演名"
    }
  ],
  "error": null,
  "explanation": "查询评分最高的5部电影，按评分降序排列"
}
```

## 🔧 技术实现

### 架构设计

```
┌─────────────┐      ┌──────────────┐      ┌──────────────┐
│  用户问题    │ ───> │  SQL生成器   │ ───> │  SQL执行器   │
└─────────────┘      └──────────────┘      └──────────────┘
                             │                      │
                             │                      │
                             v                      v
                     ┌──────────────┐      ┌──────────────┐
                     │  规则匹配    │      │  结果格式化  │
                     └──────────────┘      └──────────────┘
```

### 核心组件

1. **SQLAgent 类**
   - 负责将自然语言转换为 SQL
   - 使用规则匹配方式生成 SQL
   - 支持多种查询模式

2. **安全机制**
   - 仅支持 SELECT 查询
   - 禁止 UPDATE、DELETE、DROP 等危险操作
   - 参数化查询防止 SQL 注入

3. **数据库结构**
   - 内置完整的数据库表结构信息
   - 支持多表关联查询

---

## 📊 数据库表结构

系统包含以下主要表：

1. **sakura_movtype** - 电影类型表
2. **sakura_movinfo** - 电影信息表
3. **sakura_movdetail** - 电影详情表
4. **sakura_user** - 用户表
5. **sakura_comment** - 评论表
6. **sakura_user_collection** - 用户收藏表

详细结构可通过 `/sql-agent/schema` 接口获取。

## 📝 注意事项

1. **查询限制**
   - 为保护性能，大部分查询默认限制返回 10 条记录
   - 可在问题中指定数量，如"查询前20部电影"

2. **数据格式**
   - 日期时间会转换为 ISO 格式字符串
   - 空值字段会保留为 null

3. **性能优化**
   - 使用异步数据库查询
   - 合理使用索引字段

## ❓ 常见问题

**Q: 为什么我的问题没有返回结果？**  
A: 请检查数据库中是否有对应数据，或尝试使用示例问题。

**Q: 如何提出更复杂的查询？**  
A: 当前版本使用规则匹配，建议参考示例问题。未来版本将支持更复杂的自然语言理解。

**Q: 是否支持自定义 SQL？**  
A: 出于安全考虑，暂不支持直接执行自定义 SQL。
